### 💼 Project Highlights

Here are some of my favorite works 👇

**🏢 ITAS Tax System Suite**
- 🧾 **Tax Audit Core Server** (`bs-taxaudit-core-server`) – Hexagonal/DDD backend for the full audit lifecycle — 9 domain clusters, 15 aggregates, 30 business use cases, with auto-generated PlantUML activity diagrams
- 📝 **Registration Core Server** (`bs-registration-core-server`) – Spring Boot 3.3 / Java 21 microservice for TIN registration, with domain aggregates like `TaxAgent` and `TaxpayerChangeRequest` driven by event-based state machines
- ⚠️ **Tax Risk Assessment Engine** – Rule-based backend scoring taxpayer risk from filing, payment, and compliance data, feeding directly into audit case selection
- 🗺️ **Domain Modeling & Docs** – Interactive Mermaid domain model (17 classes) and an auditor dashboard mockup built on the Ministry of Revenues brand palette

**Other Projects**
- 🚗 [**Transport Management System**](https://github.com/Paul-dir/transport-management-system) – Web app for managing transport requests
- 📱 [**Attendance Mobile App**](https://github.com/Paul-dir/Attendance-mobile-app) – Android app for class attendance tracking
- 💼 [**Task Manager**](https://github.com/Paul-dir/task-manager) – Task tracking with PHP backend
- 🧰 [**Garage Web**](https://github.com/Paul-dir/garage-web) – Employee dashboard for job status and work logs
- ⚡ [**Next.js Demo App**](https://github.com/Paul-dir/nextjs-demo) – Modern frontend app built with **Next.js + Tailwind CSS**
